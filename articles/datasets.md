# Datasets

## Datasets

The `harsat` package provides three standard datasets to help you get
started. These aren’t R data files, instead they are zip files that
contain everything you need for the analyses.

### HELCOM

- [Download the data](http://osparcomm.github.io/HARSAT/helcom.zip)
- [Worked
  example](http://osparcomm.github.io/HARSAT/articles/example_HELCOM.md)

### OSPAR

- [Download the data](http://osparcomm.github.io/HARSAT/ospar.zip)
- [Worked
  example](http://osparcomm.github.io/HARSAT/articles/example_OSPAR.md)

### AMAP (external)

- [Download the data](http://osparcomm.github.io/HARSAT/external.zip)
- [Worked
  example](http://osparcomm.github.io/HARSAT/articles/example_external_data.md)
