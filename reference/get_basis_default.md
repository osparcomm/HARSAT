# The default function for generating a basis

This default is very simplistic, but works in all cases for sediment and
water most_common was used by AMAP in their mercury assessment and takes
the most common basis reported in each station, species (biota), matrix
and determinand_group combination

## Usage

``` r
get_basis_default(data, info)
```

## Arguments

- data:

  the data

- info:

  the information object
