# Package index

## Primary functions

These are the functions you’re likely to need for any assessment. For
most standard assessments, these will be all you need.

- [`read_data()`](http://osparcomm.github.io/HARSAT/reference/read_data.md)
  : Read HARSAT data
- [`tidy_data()`](http://osparcomm.github.io/HARSAT/reference/tidy_data.md)
  : Tidy the data
- [`create_timeseries()`](http://osparcomm.github.io/HARSAT/reference/create_timeseries.md)
  : Create a time series
- [`run_assessment()`](http://osparcomm.github.io/HARSAT/reference/run_assessment.md)
  : Assess timeseries for trends and status
- [`update_assessment()`](http://osparcomm.github.io/HARSAT/reference/update_assessment.md)
  : Update timeseries assessments
- [`check_assessment()`](http://osparcomm.github.io/HARSAT/reference/check_assessment.md)
  : Check whether the assessments have converged
- [`write_summary_table()`](http://osparcomm.github.io/HARSAT/reference/write_summary_table.md)
  : Write assessment summary to a csv file
- [`plot_assessment()`](http://osparcomm.github.io/HARSAT/reference/plot_assessment.md)
  : Graphical summaries of an assessment
- [`report_assessment()`](http://osparcomm.github.io/HARSAT/reference/report_assessment.md)
  : Reports the assessment of individual time series
