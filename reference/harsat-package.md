# harsat: Harmonized Regional Seas Assessment Tool

Tools for the assessment of data concerning contaminants (hazardous
substances) and their effects in the marine environment. The code
includes tools for pre-processing data, statistical trend analysis and
comparison with threshold values, and post-processing for archiving and
reporting.
